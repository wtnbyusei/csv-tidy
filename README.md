# csv-tidy
CSVデータを使いやすい形に整えるツール。Claude Codeを活用し、要件定義から設計・実装・テストまでの開発過程を記録します。

## 開発の始め方

[uv](https://docs.astral.sh/uv/)（Python のライブラリ管理ツール）が必要です。

```sh
uv sync            # ライブラリを入れる
uv run pytest      # テストを実行する
uv run csv-tidy    # サーバーを起動する（http://127.0.0.1:8000）
```

詳しい使い方は、v0.1 の完成時にこの README に書きます。設計や開発の過程は [docs/](docs/) にあります。
