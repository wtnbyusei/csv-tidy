## 1. 文字と文字コード

コンピューターは文字を数値（バイト）として保存している。どの文字をどの数値で表すかの決まりを「文字コード」という。

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| 文字コード | ― | 文字と数値の対応表。同じバイト列でも、どの文字コードで読むかによって表示される文字が変わる |
| エンコード | encode | 文字をバイト列に変換すること。ファイルに保存するときに行う |
| デコード | decode | バイト列を文字に戻すこと。ファイルを読み込むときに行う |
| 文字化け | ― | 保存したときとは違う文字コードでデコードしたために、意味のない文字が表示されること |
| 二重エンコード | ― | 一度デコードを間違えて文字化けした状態のまま、もう一度保存してしまうこと。元に戻しにくい文字化けになる |
| UTF-8 | ユーティーエフ エイト | 世界中の文字を扱える文字コード。現在の標準で、Web や Mac、Linux で広く使われる |
| CP932 | シーピー きゅうさんに | Windows で使われる日本語の文字コード。Shift_JIS に、`①` や `髙` などの Windows 独自の文字を加えたもの。Windows 版の Excel で保存した CSV はこの文字コードになることが多い |
| Shift_JIS | シフトジス | 古くからある日本語の文字コード。CP932 の元になっている |
| UTF-16 | ユーティーエフ じゅうろく | 1文字を主に2バイトで表す文字コード。Excel の「Unicode テキスト」形式の保存で使われる。このツールでは扱わない |
| Latin-1 | ラテン ワン | 欧米の文字（アルファベットや `é` など）だけを扱う古い文字コード。二重エンコードによる文字化けの原因として出てくる |
| Unicode | ユニコード | 世界中の文字に番号を振った一覧表。UTF-8 や UTF-16 は、この番号をバイト列に変換する方式の一つ |
| U+XXXX | ユー プラス | Unicode の番号の書き方。16進数で表す。例: `A` は U+0041、全角スペースは U+3000 |
| BOM | ボム / Byte Order Mark | ファイルの先頭に付ける「この文字コードで書かれています」という目印のバイト列。UTF-8 の場合は `EF BB BF` の3バイト。Excel は BOM がないと UTF-8 の CSV を文字化けさせるため、Excel 向けには BOM 付きで保存する |
| 16進数 | じゅうろくしんすう | 0〜9 と A〜F の16種類で数を表す方法。バイトや Unicode の番号の表記に使う。`0x` を付けて `0x1A` のように書くこともある |

## 2. 改行と見えない文字

画面には表示されないが、ファイルの中には入っている文字がある。

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| 改行コード | ― | 「ここで行が終わる」ことを表す見えない文字。OS によって使う文字が違う |
| CR | キャリッジ リターン / Carriage Return | 改行コードに使う文字の一つ（U+000D）。タイプライターで印字位置を行の先頭に戻す動作が由来 |
| LF | ラインフィード / Line Feed | 改行コードに使う文字の一つ（U+000A）。紙を1行送る動作が由来。Mac や Linux の改行は LF だけを使う |
| CRLF | シーアール エルエフ | CR と LF を続けた2文字の改行。Windows の標準の改行 |
| タブ | Tab | 字下げや区切りに使う見えない文字（U+0009） |
| 制御文字 | せいぎょもじ | 文字を表示するためではなく、機器を制御するために決められた文字。改行やタブも制御文字の一種。それ以外の制御文字が普通のデータに入っていることはまれなので、入っていれば壊れたデータの可能性がある |
| NUL | ヌル | 番号が0の制御文字（U+0000）。テキストファイルにはまず入っていないため、画像や Excel ファイルなど CSV ではないファイルを見分ける手がかりにする |
| DEL | デリート | 番号が U+007F の制御文字。普通のデータにはまず出てこない |
| C1 制御文字 | シーワン せいぎょもじ | U+0080〜U+009F の範囲の制御文字。普通のデータにはまず出てこないが、二重エンコードによる文字化けで現れることがある |
| 私用領域 | しようりょういき / Private Use Area | Unicode で、決まった文字を割り当てず自由に使えるようにしてある番号の範囲（U+E000〜U+F8FF など）。Python の CP932 は、文字が割り当てられていないバイトの一部をこの範囲の文字として読む |
| NBSP | エヌビーエスピー / No-Break Space | 見た目は普通の半角スペースだが、別の文字（U+00A0）。「ここで改行しない空白」という意味を持つ。Web ページからコピーした文字によく混ざっている |
| 全角スペース | ― | 日本語入力で入る幅の広い空白（U+3000） |
| ゼロ幅文字 | ゼロはばもじ | 幅がゼロで、画面にはまったく表示されない文字。ゼロ幅スペース（U+200B）など。Web ページからのコピーで混ざることがある |
| ZWSP | Zero Width Space | ゼロ幅スペース（U+200B）の略。差分表示では `[ZWSP]` のように記号で見える形にする |

## 3. CSV とファイル形式

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| CSV | シーエスブイ / Comma-Separated Values | 表のデータを、値をカンマ（`,`）で区切ったテキストで表すファイル形式 |
| TSV | ティーエスブイ / Tab-Separated Values | 値をタブで区切る形式。CSV の仲間。このツールの v0.1 では扱わない |
| RFC 4180 | アールエフシー よんいちはちまる | CSV の書き方を定めた公開文書。RFC はインターネット関連の技術仕様を定めた文書群の名前 |
| クォート | quote | 値を囲む `"`（ダブルクォート）。値の中にカンマや改行を含めたいときに使う。例: `"山田, 太郎"`。値の中に `"` そのものを入れたいときは `""` と2つ重ねる |
| ヘッダー行 | header | CSV の1行目にある、列の名前を並べた行 |
| レコード | record | CSV の1件分のデータ。通常は1行だが、クォート内に改行を含むと複数行にまたがる |
| セル | cell | 表の1マス分の値 |
| xlsx | エックスエルエスエックス | Excel の標準のファイル形式。中身は ZIP 形式で圧縮されているため、CSV として読むことはできない |
| ZIP | ジップ | 複数のファイルを圧縮してまとめる形式。ファイルの先頭が `PK` で始まる |
| PNG | ピング | 画像のファイル形式の一つ |
| MB | メガバイト | ファイルの大きさの単位。1MB はおよそ100万バイト |
| バイト | byte | データの大きさの基本単位。半角英数字1文字はおよそ1バイト。このツールでは 10MB を 10×1024×1024 = 10,485,760 バイトと定める |

## 4. 整形処理

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| 整形 | ― | データを使いやすい形に整えること。このツールの目的 |
| トリム | trim | 値の前後にある空白を取り除くこと。例: `␣山田␣` → `山田`（`␣` は空白を表す） |
| 正規化 | せいきか | 表記の揺れを1つの形にそろえること。例: 改行コードを LF にそろえる、日付を `2026-09-24` の形にそろえる |
| 解析（パース） | parse | テキストを読んで、決まりに従って構造（ここでは行とセル）に分解すること |
| 差分 | さぶん / diff | 変更前と変更後の違い |
| 有限状態機械 | ゆうげんじょうたいきかい | 「今どの状態にいるか」と「次に来た文字」で次の状態が決まる仕組み。CSV の解析では「クォートの内側か外側か」を状態として持つ |
| 正規表現 | せいきひょうげん / regular expression | 文字の並びのパターンを書く記法。例: `[\u200b-\u200d]` は「U+200B から U+200D のどれか1文字」。文字列の中から当てはまる部分を速く探せる |

## 6. セキュリティ

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| エスケープ | escape | 特別な意味を持つ文字を、ただの文字として扱われる形に置き換えること。例: HTML で `<` を `&lt;` に置き換えると、タグとして解釈されなくなる |
| XSS | クロスサイトスクリプティング | 画面に表示したデータがプログラムとして実行されてしまう攻撃。例: セルの値 `<script>...</script>` がそのまま HTML に入ると実行される。エスケープで防ぐ |
| CSV インジェクション | ― | CSV の値が `=` などで始まっていると、Excel で開いたときに数式として実行される問題 |
| 無害化 | むがいか | 危険な値を安全な形に変えること。CSV インジェクションでは値の先頭に `'` を付けるなどの方法がある。このツールでは行わない |

| HTTP ステータス | ― | サーバーが結果の種類を示す番号。200 は成功、413 はデータが大きすぎる、422 は内容を処理できない |
| base64 | ベースろくじゅうよん | バイト列を文字に変換する方式。データ量はおよそ 1.33 倍になる |
| `textContent` / `innerHTML` | テキストコンテント / インナーエイチティーエムエル | 画面に文字を入れる JavaScript の方法。`textContent` は文字のまま入れ、`innerHTML` は HTML として解釈する。安全のため `textContent` を使う |

## 9. サーバーと公開

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| レンタルサーバー（共有サーバー） | ― | 1台のサーバーを多くの利用者で共有するサービス。ファイルを置くだけで Web サイトを公開できるが、できることに制限がある。例: ConoHa WING |
| VPS | ブイピーエス / Virtual Private Server | 自分専用の仮想サーバーを借りるサービス。OS から自分で管理するため自由度が高い。例: ConoHa VPS |
| SSH | エスエスエイチ / Secure Shell | サーバーに遠隔でログインして操作するための仕組み |
| CGI | シージーアイ / Common Gateway Interface | リクエストが来るたびにプログラムを起動し、処理が終わると終了する古い方式。レンタルサーバーでよく使える |
| 常駐プロセス | じょうちゅうプロセス | 起動したまま動き続けて、リクエストを待つプログラム。uvicorn はこの形で動く。レンタルサーバーでは一般に許可されない |
| ASGI / WSGI | エーエスジーアイ / ウィズギー | Python の Web アプリとサーバーをつなぐ方式の規格。FastAPI は ASGI、Flask などは WSGI。CGI とは方式が違う |
| リクエスト | request | ブラウザからサーバーへの要求 |
| リバースプロキシ | reverse proxy | 外からの通信を受け取り、裏で動くアプリに中継するサーバー。Nginx（エンジンエックス）が代表例 |
| NFKC 正規化 | エヌエフケーシー | Unicode の規格で定められた、見た目が同じ仲間の文字を1つの形にそろえる変換。全角英数字を半角にできるが、`①` → `1` や `㈱` → `(株)` など意図しない変換も起きる |
| スレッド | thread | 1つのプログラムの中で、複数の処理を並行して動かす仕組み。ブラウザ内の Python（Pyodide）では使えない |
| `Content-Disposition` | コンテント ディスポジション | サーバーの応答に付ける付加情報（ヘッダー）の一つ。保存するファイル名を指定できるが、日本語の名前には RFC 5987 形式という特別な書き方が必要 |
| `download` 属性 | ダウンロード ぞくせい | HTML のリンクに付けると、そのリンクを押したときに指定した名前でファイルを保存させる |
| GitHub Pages | ギットハブ ページズ | GitHub の無料のサイト公開機能。HTML などのファイルを置くだけで公開できる。v0.4（候補）の公開先 |
| ワイヤーフレーム | wireframe | 画面に何をどこに置くかだけを描いた下書き。色や装飾は決めない |
| VLOOKUP | ブイルックアップ | Excel で、表から値を探して取り出す関数。表記のゆれがあると一致しない |
| ドラッグ＆ドロップ | drag and drop | ファイルなどをマウスで引っ張ってきて、目的の場所で放す操作 |
| タブ（画面） | tab | 画面の中で、見出しを押して表示する内容を切り替える仕組み。タブ文字（U+0009）とは別のもの |
| バッジ | badge | 状態や種類を示す、色付きの小さな札 |
| 凡例 | はんれい | 図や表で使っている色や記号の意味を説明したもの |
| 見本（モック） | mock | 見た目だけを再現した、動かない画面。このプロジェクトでは `docs/mockups/` の HTML |

## 10. テスト

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| E2E テスト | イートゥーイー / End to End | 本物のブラウザをプログラムで動かし、画面の操作から結果までを通して確かめるテスト |
| Playwright | プレイライト | ブラウザをプログラムで操作するための道具。E2E テストに使う |
| カバレッジ | coverage | テストで実行されたコードの割合。行カバレッジは実行された行の割合、分岐カバレッジは `if` などの両側が実行された割合 |
| pytest-cov | パイテスト コブ | pytest でカバレッジを測るための追加の道具 |
| プロパティベーステスト | property-based testing | ランダムな入力を大量に作り、「どんな入力でも成り立つ性質」が崩れないかを確かめるテスト |
| Hypothesis | ハイポセシス | Python でプロパティベーステストを書くための道具 |
| べき等 | べきとう | 同じ操作を何回行っても、1回行ったときと結果が変わらない性質 |
| 回帰テスト | かいきテスト | 一度直した不具合が再び起きていないことを確かめるテスト |
| 対応表（トレーサビリティ） | traceability | 要件とテストを1対1で結び付けた表。要件のテスト漏れを見つけるために使う |
| マーカー | marker | pytest でテストに付ける目印。目印ごとに実行する・しないを選べる。例: `perf` |
| フィクスチャ | fixture | テストで使うために用意しておくデータやファイル。このプロジェクトでは `tests/fixtures/` に置く CSV |
| pyproject.toml | パイプロジェクト トムル | Python のプロジェクトの設定ファイル。名前・版・使うライブラリ・テストの設定などを書く |
| .gitignore | ギット イグノア | Git で記録しないファイルを指定するファイル。テストの実行で作られる一時ファイルなどを書く |
| マトリックス | matrix | GitHub Actions で、同じジョブを条件（Python の版など）を変えて何回か実行する仕組み |
| キャッシュ | cache | 一度ダウンロードしたものを保存しておき、次回に再利用して速くする仕組み |
| エントリーポイント | entry point | プログラムを起動する入口。このプロジェクトでは `uv run csv-tidy` で `csv_tidy/__main__.py` の `main` が動く |
| httpx | エイチティーティーピーエックス | Python で HTTP の通信をするライブラリ。FastAPI の TestClient が内部で使う |
| python-multipart | パイソン マルチパート | FastAPI がファイルのアップロード（multipart/form-data）を受け取るために使うライブラリ |
