要件定義書（[requirements.md](requirements.md)）と課題管理（[issues.md](issues.md)）で使っている用語をまとめる。
ドキュメントに新しい用語を使うときは、ここにも追記する。

- 作成日: 2026-09-25

## 1. 文字と文字コード

コンピューターは文字を数値（バイト）として保存している。どの文字をどの数値で表すかの決まりを「文字コード」という。

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| 文字コード | ― | 文字と数値の対応表。同じバイト列でも、どの文字コードで読むかによって表示される文字が変わる |
| エンコード | encode | 文字をバイト列に変換すること。ファイルに保存するときに行う |
| デコード | decode | バイト列を文字に戻すこと。ファイルを読み込むときに行う |
| 文字化け | ― | 保存したときとは違う文字コードでデコードしたために、意味のない文字が表示されること |
| 二重エンコード | ― | 一度デコードを間違えて文字化けした状態のまま、もう一度保存してしまうこと。元に戻しにくい文字化けになる |
| UTF-8 | ユーティーエフ エイト | 世界中の文字を扱える文字コード。現在の標準で、Web や Mac、Linux で広く使われる |
| CP932 | シーピー きゅうさんに | Windows で使われる日本語の文字コード。Shift_JIS に、`①` や `髙` などの Windows 独自の文字を加えたもの。Windows 版の Excel で保存した CSV はこの文字コードになることが多い |
| Shift_JIS | シフトジス | 古くからある日本語の文字コード。CP932 の元になっている |
| UTF-16 | ユーティーエフ じゅうろく | 1文字を主に2バイトで表す文字コード。Excel の「Unicode テキスト」形式の保存で使われる。このツールでは扱わない |
| Latin-1 | ラテン ワン | 欧米の文字（アルファベットや `é` など）だけを扱う古い文字コード。二重エンコードによる文字化けの原因として出てくる |
| Unicode | ユニコード | 世界中の文字に番号を振った一覧表。UTF-8 や UTF-16 は、この番号をバイト列に変換する方式の一つ |
| U+XXXX | ユー プラス | Unicode の番号の書き方。16進数で表す。例: `A` は U+0041、全角スペースは U+3000 |
| BOM | ボム / Byte Order Mark | ファイルの先頭に付ける「この文字コードで書かれています」という目印のバイト列。UTF-8 の場合は `EF BB BF` の3バイト。Excel は BOM がないと UTF-8 の CSV を文字化けさせるため、Excel 向けには BOM 付きで保存する |
| 16進数 | じゅうろくしんすう | 0〜9 と A〜F の16種類で数を表す方法。バイトや Unicode の番号の表記に使う。`0x` を付けて `0x1A` のように書くこともある |

## 2. 改行と見えない文字

画面には表示されないが、ファイルの中には入っている文字がある。

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| 改行コード | ― | 「ここで行が終わる」ことを表す見えない文字。OS によって使う文字が違う |
| CR | キャリッジ リターン / Carriage Return | 改行コードに使う文字の一つ（U+000D）。タイプライターで印字位置を行の先頭に戻す動作が由来 |
| LF | ラインフィード / Line Feed | 改行コードに使う文字の一つ（U+000A）。紙を1行送る動作が由来。Mac や Linux の改行は LF だけを使う |
| CRLF | シーアール エルエフ | CR と LF を続けた2文字の改行。Windows の標準の改行 |
| タブ | Tab | 字下げや区切りに使う見えない文字（U+0009） |
| 制御文字 | せいぎょもじ | 文字を表示するためではなく、機器を制御するために決められた文字。改行やタブも制御文字の一種。それ以外の制御文字が普通のデータに入っていることはまれなので、入っていれば壊れたデータの可能性がある |
| NUL | ヌル | 番号が0の制御文字（U+0000）。テキストファイルにはまず入っていないため、画像や Excel ファイルなど CSV ではないファイルを見分ける手がかりにする |
| DEL | デリート | 番号が U+007F の制御文字。普通のデータにはまず出てこない |
| C1 制御文字 | シーワン せいぎょもじ | U+0080〜U+009F の範囲の制御文字。普通のデータにはまず出てこないが、二重エンコードによる文字化けで現れることがある |
| NBSP | エヌビーエスピー / No-Break Space | 見た目は普通の半角スペースだが、別の文字（U+00A0）。「ここで改行しない空白」という意味を持つ。Web ページからコピーした文字によく混ざっている |
| 全角スペース | ― | 日本語入力で入る幅の広い空白（U+3000） |
| ゼロ幅文字 | ゼロはばもじ | 幅がゼロで、画面にはまったく表示されない文字。ゼロ幅スペース（U+200B）など。Web ページからのコピーで混ざることがある |
| ZWSP | Zero Width Space | ゼロ幅スペース（U+200B）の略。差分表示では `[ZWSP]` のように記号で見える形にする |

## 3. CSV とファイル形式

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| CSV | シーエスブイ / Comma-Separated Values | 表のデータを、値をカンマ（`,`）で区切ったテキストで表すファイル形式 |
| TSV | ティーエスブイ / Tab-Separated Values | 値をタブで区切る形式。CSV の仲間。このツールの v0.1 では扱わない |
| RFC 4180 | アールエフシー よんいちはちまる | CSV の書き方を定めた公開文書。RFC はインターネット関連の技術仕様を定めた文書群の名前 |
| クォート | quote | 値を囲む `"`（ダブルクォート）。値の中にカンマや改行を含めたいときに使う。例: `"山田, 太郎"`。値の中に `"` そのものを入れたいときは `""` と2つ重ねる |
| ヘッダー行 | header | CSV の1行目にある、列の名前を並べた行 |
| レコード | record | CSV の1件分のデータ。通常は1行だが、クォート内に改行を含むと複数行にまたがる |
| セル | cell | 表の1マス分の値 |
| xlsx | エックスエルエスエックス | Excel の標準のファイル形式。中身は ZIP 形式で圧縮されているため、CSV として読むことはできない |
| ZIP | ジップ | 複数のファイルを圧縮してまとめる形式。ファイルの先頭が `PK` で始まる |
| PNG | ピング | 画像のファイル形式の一つ |
| MB | メガバイト | ファイルの大きさの単位。1MB はおよそ100万バイト |

## 4. 整形処理

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| 整形 | ― | データを使いやすい形に整えること。このツールの目的 |
| トリム | trim | 値の前後にある空白を取り除くこと。例: `␣山田␣` → `山田`（`␣` は空白を表す） |
| 正規化 | せいきか | 表記の揺れを1つの形にそろえること。例: 改行コードを LF にそろえる、日付を `2026-09-24` の形にそろえる |
| 解析（パース） | parse | テキストを読んで、決まりに従って構造（ここでは行とセル）に分解すること |
| 差分 | さぶん / diff | 変更前と変更後の違い |
| 有限状態機械 | ゆうげんじょうたいきかい | 「今どの状態にいるか」と「次に来た文字」で次の状態が決まる仕組み。CSV の解析では「クォートの内側か外側か」を状態として持つ |

## 5. アプリの構成と技術

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| Python | パイソン | このツールの実装に使うプログラミング言語 |
| FastAPI | ファストエーピーアイ | Python で Web の API を作るためのライブラリ |
| API | エーピーアイ / Application Programming Interface | プログラム同士がやり取りするための窓口。このツールでは、画面（ブラウザ）が API にファイルを送り、サーバーが整形結果を返す |
| サーバー | server | 処理を行って結果を返すプログラム。このツールでは自分の PC 上で動かす |
| ブラウザ | browser | Chrome や Edge など、Web ページを表示するソフト。このツールの画面はブラウザで表示する |
| フロントエンド | frontend | 利用者が見て操作する画面の部分。HTML と JavaScript で作る |
| HTML | エイチティーエムエル | Web ページの構造を書くための言語 |
| JS（JavaScript） | ジャバスクリプト | ブラウザ上で動くプログラミング言語。画面の操作に反応する処理を書く |
| UI | ユーアイ / User Interface | 利用者が操作する画面やボタンなどのこと |
| 127.0.0.1 | ローカルホスト | 自分の PC 自身を指す住所（IP アドレス）。サーバーをこの住所だけで待ち受けると、他の PC からは接続できない |
| ステートレス | stateless | サーバーが利用者ごとのデータを保存しない作り。必要なデータは毎回ブラウザから送ってもらう |
| pytest | パイテスト | Python でテストを書いて実行するためのツール |
| `csv` モジュール | ― | Python に標準で付いている、CSV を読み書きする部品 |
| `strict=True` | ストリクト | `csv` モジュールの設定の一つ。CSV の書き方の誤りをエラーとして検出する |
| `str.strip()` | ストリップ | Python で文字列の前後の空白を取り除く機能。何も指定しないと、このツールで決めた範囲より多くの文字を取り除く |
| Streamlit / Flask / Pyodide | ― | 構成を検討したときに比べた、Python で Web アプリを作る別の方法。いずれも採用しなかった |
| VSCode / WinMerge | ― | ファイルの差分を左右に並べて表示できるソフト。差分表示の参考にした |

## 6. セキュリティ

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| エスケープ | escape | 特別な意味を持つ文字を、ただの文字として扱われる形に置き換えること。例: HTML で `<` を `&lt;` に置き換えると、タグとして解釈されなくなる |
| XSS | クロスサイトスクリプティング | 画面に表示したデータがプログラムとして実行されてしまう攻撃。例: セルの値 `<script>...</script>` がそのまま HTML に入ると実行される。エスケープで防ぐ |
| CSV インジェクション | ― | CSV の値が `=` などで始まっていると、Excel で開いたときに数式として実行される問題 |
| 無害化 | むがいか | 危険な値を安全な形に変えること。CSV インジェクションでは値の先頭に `'` を付けるなどの方法がある。このツールでは行わない |

## 7. 開発の進め方とドキュメント

| 用語 | 読み方・正式名 | 説明 |
| --- | --- | --- |
| 要件定義 | ようけんていぎ | 何を作るか、何ができればよいかを決めること |
| MVP | エムブイピー / Minimum Viable Product | 必要最小限の機能を持った最初の版。このツールでは v0.1 |
| v0.1 など | バージョン | リリースの版の番号。v0.1 → v0.2 → v0.3 の順に機能を増やす |
| FR | Functional Requirement | 機能要件。「何ができるか」の要件。例: FR-20 |
| NFR | Non-Functional Requirement | 非機能要件。性能やセキュリティなど「どのくらいの品質で動くか」の要件。例: NFR-07 |
| 受け入れ基準 | うけいれきじゅん | 完成したと判断するために確認する条件 |
| スコープ | scope | 作る範囲。「スコープ外」は今回は作らないもの |
| H1 / M1 / L1 / Q1 | ― | 課題管理の ID。H は重要度「高」（High）、M は「中」（Medium）、L は「低」（Low）、Q は検討事項（Question） |
| README | リードミー | リポジトリの説明書。最初に読むファイル |
| Git | ギット | ファイルの変更履歴を記録する仕組み |
| コミット | commit | 変更を Git の履歴に記録すること |
| プッシュ | push | 記録した変更を GitHub などのサーバーに送ること |
| ブランチ | branch | 変更を並行して進めるための、履歴の枝分かれ |
